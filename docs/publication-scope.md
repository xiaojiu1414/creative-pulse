# Publication scope

## Included

- Product description and a high-level service diagram.
- HTTP entry scaffold and an abstract backend interface.
- Public prototype and demonstration-video links.
- Evaluator walkthrough and directions for receiving access privately.
- Checks of scaffold behavior and the approved publication boundary.

## Separately maintained material

The product backend, model components, inference logic, internal instructions,
training and evaluation assets, parameter settings, weights, processing
algorithms, detailed schemas, application source snapshots, and generated
analytical results are maintained separately.

Login identifiers, passwords, tokens, and credential-bearing documents are
excluded from this repository. The original submission deck is distributed
separately because it contains evaluator access information.

The public scaffold cannot recreate the complete Creative Pulse product.
The online prototype and demonstration video present the user experience.
This repository is a technical submission companion; the product implementation
is maintained privately.

`PUBLIC_FILES.json` lists the only files intended for publication. Additions
require a deliberate review of this boundary. No open-source license is granted
for the separately maintained product implementation.
